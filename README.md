# Калькулятор дозировок — Telegram Mini App и офлайн-версия

## Что в папке
| Файл | Зачем |
|---|---|
| `index.html` | сам калькулятор (обе вкладки), с поддержкой Telegram и офлайна |
| `sw.js` | сохраняет калькулятор на телефоне, чтобы он работал без интернета |
| `manifest.webmanifest`, `icon-*.png` | название и иконка при установке на главный экран |
| `build.py` | пересобирает `index.html` из `../dose-calculator.html` после правок |

## 1. Разместить на GitHub Pages (бесплатно, https)
1. Зайдите на github.com → **New repository** → имя, например `doza` → **Public** → Create.
2. На странице репозитория: **Add file → Upload files** → перетащите все файлы из этой папки (кроме `build.py` и `README.md` — их можно не загружать) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты появится адрес `https://ВАШ-ЛОГИН.github.io/doza/` — откройте его на телефоне и проверьте.

## 2. Подключить к боту в Telegram
1. Откройте **@BotFather** → `/newbot` → придумайте имя и username бота.
2. `/mybots` → выберите бота → **Bot Settings → Menu Button → Configure menu button** → вставьте адрес из шага 1.4 → назовите кнопку, например «Калькулятор».
3. Откройте своего бота: слева от поля ввода появится кнопка — калькулятор откроется внутри Telegram.
4. По желанию: `/newapp` в BotFather создаёт ссылку вида `t.me/бот/app` — её удобно пересылать коллегам.

Токен бота никому передавать не нужно: сервер для Mini App не требуется.

## 3. Офлайн
- После первого открытия с интернетом калькулятор сохраняется на устройстве. Внизу страницы появится строка «Сохранено на устройстве».
- В браузере телефона: «Поделиться → На экран „Домой“» (iPhone, Safari) или «Установить приложение» (Android, Chrome) — иконка «Дозировки» откроется и без сети.
- Внутри Telegram офлайн зависит от платформы: на Android обычно работает, на iPhone Telegram может не открыть Mini App без сети. Для вызовов без связи надёжнее иконка на главном экране.

## 4. Обновление
1. Поправьте калькулятор → `python build.py`.
2. В `sw.js` увеличьте `VERSION` (`doza-v1` → `doza-v2`).
3. Загрузите `index.html` и `sw.js` в репозиторий заново. Телефоны подхватят новую версию при следующем открытии с интернетом.

> Страница по адресу GitHub Pages открыта всем, у кого есть ссылка. Данные пациента никуда не отправляются — расчёт идёт на устройстве.
